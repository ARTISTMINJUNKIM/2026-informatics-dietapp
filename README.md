# 김민준

* 트랙: 앱웹개발
* 주제 한 문장: 식단과 운동을 꾸준히 관리하고 싶은 사람을 위해, 먹은 음식과 운동·영양제를 한 앱에 기록하면 칼로리와 영양소를 자동으로 계산해 주는 프로그램
* 핵심 기능(1가지):
  * **음식 검색 기반 식단 기록** — 음식 이름을 검색해 아침·점심·저녁·간식에 추가하면 칼로리, 탄수화물, 단백질, 지방을 자동으로 합산하고 목표 대비 몇 %인지 보여준다. FatSecret(해외 음식과 브랜드 제품)과 식약처 식품영양성분 DB(한국음식검색)를 동시에 검색해 데이터 수를 최대한 늘렸다.
* 추가하고 싶은 기능(2~3가지):
  1. **웨이트 운동 상세 기록** — 종목별 무게·횟수·세트 종류(워밍업/드롭/실패)와 세트마다 쉰 시간을 기록하고, 체중과 운동 시간으로 소모 칼로리를 추정해 식단 목표에 반영
  2. **영양제 복용 체크** — 영양제를 시간대(아침·점심·저녁·자기 전)별로 등록하고 매일 체크, 주간 복용률 확인
* 쓰일 알고리즘·자료구조 예상:
  * **해시맵(딕셔너리)** — 날짜를 키로 그날의 식단,운동,건강 기록을 저장해 날짜별 조회를 O(1)로 처리
  * **배열(리스트)** — 식사별 음식 목록, 운동 종목별 세트 목록을 순서대로 저장하고 순회하며 합계 계산
  * **집합(Set)을 이용한 중복 제거** — 두 음식 DB의 검색 결과를 합칠 때 (이름, 브랜드, 칼로리)가 같은 항목을 한 번만 표시
  * **병렬 처리 + 우선순위 병합** — 두 API를 동시에 호출하고, 검색어가 한글이면 식약처 결과를, 영문이면 FatSecret 결과를 앞에 배치
  * **정렬 + 역순 탐색** — 기록된 날짜를 정렬한 뒤 최근 날짜부터 거슬러 올라가며 같은 운동 종목의 지난 기록(무게·횟수·휴식)을 찾아 미리 채우기
  * **연속 기록(streak) 계산** — 오늘부터 하루씩 거꾸로 순회하며 기록이 끊기기 전까지 일수를 셈
  * **캐시** — API 인증 토큰을 만료 시간과 함께 저장해 두고 재사용해서 불필요한 요청을 줄임
  * **디바운싱** — 검색어 입력이 0.35초 멈췄을 때만 요청을 보내 서버 호출 횟수를 줄임
  * **계산식** — 칼로리 = 탄수×4 + 단백질×4 + 지방×9, 운동 소모 칼로리 = 운동 강도(MET) × 체중 × 운동 시간
